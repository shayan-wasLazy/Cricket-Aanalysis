# Raw data

Place the six authorized SupeRR Selector source tables in this folder:

- ball_by_ball.csv (or ball_by_ball.csv.gz)
- matches.csv
- competitions.csv
- teams.csv
- playing_eleven.csv
- competition_team_player_mapping.csv

This public repository includes convenience copies of matches.csv, competitions.csv and teams.csv. The remaining large/competition-provided source files are kept in the local project bundle rather than redistributed from this public repository. Check the competition's data terms before sharing source data publicly.
